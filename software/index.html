Software

Open-source tools developed in the laboratory. More on GitHub.

  • F-16 Model

    Julia · MATLAB/Simulink

    Nonlinear F-16 aircraft model. Aerodynamics from NASA Technical Report 1538 (Nguyen et al., 1979); model structure follows Stevens & Lewis, Aircraft Control and Simulation (Wiley, 1992).

    Julia packageMATLAB/Simulink

  • Robust Control Toolbox

    Julia

    Julia implementation of robust control design and analysis algorithms: linear system objects, standard response plots, and system interconnections. Under active development.

    GitHub

  • Maximum Entropy Basis Functions

    Julia

    Dimension-agnostic maximum-entropy basis functions and their first derivatives, implementing Arroyo & Ortiz, "Local maximum-entropy approximation schemes."

    GitHub

  • Multibody Dynamics

    Julia

    Multibody dynamics using the Udwadia–Kalaba formulation, with a range of joint types.

    GitHub

  • STEDY

    MATLAB

    Software for TEnsegrity DYnamics. Network topology via connectivity matrices; Lagrangian dynamics with non-minimal coordinates and holonomic constraints, with corrections for constraint violation and energy drift.

    GitHubUser guidePaper

  • OPTRAGEN

    MATLAB

    MATLAB toolbox for optimal control problems. Runs on fmincon; the SNOPT dependency has been removed.

    GitHubManual (PDF)
